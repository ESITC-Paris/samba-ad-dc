PRIVILEGED-PORT CROSS-CHECK
---------------------------
  Docker sets net.ipv4.ip_unprivileged_port_start=0 in the network
  namespace it creates for a container, which makes 53/88/389/445
  unprivileged there. Under the E2E suite (a user-defined bridge)
  NET_BIND_SERVICE therefore measures droppable no matter what the
  image needs. SPEC B.3 also supports HOST networking, where the
  container inherits the host's value — 1024 on any ordinary Linux
  system. The probe below forces the floor back to 1024 and binds
  :389 in this image, with the capability and without it:

    without NET_BIND_SERVICE : denied
    with    NET_BIND_SERVICE : bound

  => NET_BIND_SERVICE is REQUIRED wherever the port floor is at the
     kernel default. Its 'droppable' verdict above is a property of
     the test runtime, not of the image, and it is RETAINED in the
     shipped profile.
